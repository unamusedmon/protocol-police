# Transport Layer Security (TLS) 1.3

## Introduction

The primary goal of the TLS protocol is to provide authentication, confidentiality, and integrity between two communicating endpoints.

## Protocol Structure

TLS is composed of two primary components:
1. A Handshake Protocol
2. A Record Protocol

## Handshake Protocol

The TLS handshake protocol is used to establish the security parameters of a connection.

```svgbob
       Client                                               Server

       Key  ^ ClientHello                          -------->
       Exch | + key_share*
            | + signature_algorithms*
            | + psk_key_exchange_modes*
            V + pre_shared_key*                     ServerHello  ^ Key
                                                   + key_share*  | Exch
                                              + pre_shared_key*  V
                                                                 
                                          {EncryptedExtensions}  ^  Params
                                          {CertificateRequest*}  |
                                                 {Certificate*}  |
                                           {CertificateVerify*}  V
                                                     {Finished}  ^  Auth
                                                                 V
            ^ {Certificate*}               <-------- [Application Data*]
       Auth | {CertificateVerify*}
            V {Finished}                   -------->

       [Application Data]                  <-------> [Application Data]

              +  Indicates noteworthy extensions sent in the
                 previously noted message.

              *  Indicates optional or situation-dependent
                 messages/extensions that are not always sent.

              {} Indicates messages protected using keys
                 derived from a [sender]_handshake_traffic_secret.

              [] Indicates messages protected using keys
                 derived from [sender]_application_traffic_secret_N.
```

## Record Protocol

The TLS record protocol is a layered protocol. At each layer, messages may include fields for length, description, and content. The record protocol takes messages to be transmitted, fragments the data into manageable blocks, optionally compresses the data, applies a MAC, encrypts, and transmits the result.
